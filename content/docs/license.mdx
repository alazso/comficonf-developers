[Apache License, Version 2.0](https://www.apache.org/licenses/LICENSE-2.0). You can compile against the API and
use the demo plugin's code in your own plugin under the terms of that license. The API's POM declares the
license, and the full text is the `LICENSE` file of the <ReleaseLink to="apiRepository">ComfiConf API repository</ReleaseLink>.

The ComfiConf bridge plugin and the ComfiConf service are not open source. Your plugin never ships the bridge: it
compiles against the API with `compileOnly` or `provided`, and the bridge provides the API classes at runtime.
